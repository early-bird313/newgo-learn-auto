# Facebook Page AI Auto-Posting & Messenger Bot (100% Free)

একটি সম্পূর্ণ বিনামূল্যে স্বয়ংক্রিয় ফেসবুক পেজ ম্যানেজমেন্ট সিস্টেম। এটি দিয়ে আপনি পেজে নির্ধারিত সময়ে সুন্দর ছবি সহ স্বয়ংক্রিয় পোস্ট পাবলিশ করতে পারবেন এবং পেজের মেসেঞ্জারে যেকোনো গ্রাহকের বার্তার এআই দিয়ে তাৎক্ষণিক ও নির্ভুল উত্তর দিতে পারবেন।

## 🌟 মূল বৈশিষ্ট্যসমূহ (Key Features)

- 🤖 **স্মার্ট এআই চ্যাটবট (Google Gemini API)**: পেজের কাস্টম নলেজবেস অনুযায়ী কাস্টমারদের প্রশ্নের মার্জিত উত্তর প্রদান।
- 📸 **স্বয়ংক্রিয় ফটো পোস্ট**: Gemini দিয়ে আকর্ষণীয় ক্যাপশন এবং রয়্যালটি-মুক্ত হাই-রেজোলিউশন ছবি (Pollinations/Unsplash/Pexels) সহ নিয়মিত পোস্ট।
- ⏰ **দৈনিক শিডিউলার (APScheduler)**: প্রতিদিন নির্দিষ্ট সময়ে স্বয়ংক্রিয় পোস্টিং।
- ⚡ **ইনস্ট্যান্ট ম্যানুয়াল ট্রিগার**: যেকোনো সময় `/trigger-post` এন্ডপয়েন্টে ক্লিক করে তৎক্ষণাৎ পোস্ট করার সুবিধা।
- 🌐 **২৪/৭ ফ্রি ক্লাউড হোস্টিং**: Render.com-এ কোনো খরচ ছাড়া সার্বক্ষণিক ব্যাকএন্ড সার্ভিস।
- 🔒 **নিরাপদ ও ডুপ্লিকেট-রোধী**: মেটা ওয়েব হুক যাচাই ও একই মেসেজ বারবার প্রসেস হওয়া রোধ।

## 🚀 দ্রুত শুরু করার নির্দেশিকা (Quick Start)

১. রিপোজিটরি ক্লোন বা ফোল্ডারে প্রবেশ করুন:
   ```bash
   cd "d:\As Suunah\AI\web\Day 01\4th Project"
   ```

২. ভার্চুয়াল এনভায়রনমেন্ট চালু করে ডিপেন্ডেন্সি ইনস্টল করুন:
   ```bash
   uv venv .venv
   .venv\Scripts\activate
   uv pip install -r requirements.txt
   ```

৩. `.env` ফাইল কনফিগার করুন:
   `.env.example` ফাইলের নাম পরিবর্তন করে `.env` রাখুন এবং আপনার ক্রেডেনশিয়াল দিন।

৪. সার্ভার চালু করুন:
   ```bash
   uvicorn main:app --reload --port 8000
   ```

৫. ব্রাউজারে ড্যাশবোর্ড দেখুন:
   [http://localhost:8000](http://localhost:8000)
